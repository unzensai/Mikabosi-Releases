# Mikabosi

Rust製の金星儀。山脈・高地・クレーターを描いた金色の球体、星空、オルゴール風のオリジナルメロディを眺めるデスクトップアプリです。AppleシリコンMac / Windows x64向け。

## ダウンロードしたアプリを起動する

- **Mac**: `Mikabosi-macOS-AppleSilicon.zip` を展開し、アイコン付きの `Mikabosi.app` をFinderでダブルクリック。ターミナルは不要です。Applicationsフォルダに移動して使うこともできます。
- **Windows**: `Mikabosi.exe` をダブルクリック。画像・音声・ランタイムを別途インストールする必要はありません。Windows 10 / 11 x64を対象としています。

Mac版はローカルのアドホック署名です。Developer ID署名・公証は含みません。Windows版は自己署名です。配布先ではOSによる未署名アプリの確認が表示される場合があります。

## 操作

| 操作              | 機能                             |
| --------------- | ------------------------------ |
| 金星をドラッグ / 矢印キー  | 回転（自動回転を解除）                    |
| 金星上でスクロール / +・− | 拡大縮小                           |
| Space           | 自動回転の切替                        |
| M               | BGM切替                          |
| A               | 大気 / 地表 / 古代の海の表示切替            |
| G               | 目盛りの切替（起動時は非表示）                |
| H               | **操作パネル・タイトル・説明を完全に非表示 / 再表示** |
| F               | 全画面の切替                         |
| Esc             | 全画面を終了                         |
| R               | 視点を初期化                         |

UIを隠してもマウスとキーボードの操作は有効です。`H`で戻してください。`F`で全画面、`H`でUI非表示、必要に応じて`G`で目盛りを消すと鑑賞に集中できます。

起動時は大気（Atmosphere）を表示します。操作パネルのAtmosphere / Surface、または`A`キーで厚い雲に覆われた外観と地表を切り替えられます。切替時も回転角度・拡大率・自動回転の状態を保ち、UI非表示中でも`A`が使えます。大気表示は地表を覆い隠す不透明な雲頂の表現です。

**Ancient Ocean** は古代金星に海が存在したと仮定した観察モードです。生成地形の低地を一定の水位で覆い、浅瀬と深海、低地の森林帯、露出した高地、薄雲を描きます。海の存在は未確定で、海岸線はアプリ独自の表現です。

AUTO ORBITで自動回転、speedで速度、MELODYでBGM、volumeで音量を変更できます。音楽は76 BPM・24小節のオリジナルのワルツで、柔らかいオルゴールの音色にアルペジオと残響を重ねています。


## 表現と検証

地表は独自生成した高低差マップと法線マップによる、金星をイメージした芸術的表現です。大気の雲頂と、雲を取り除いた地表を別々に鑑賞するもので、実測地形・気象・自転速度の精密シミュレーションではありません。
音楽・地表データは実行ファイルに内蔵しています。
